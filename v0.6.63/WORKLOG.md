# WORKLOG — v0.6.63（体素固化：三角形直接用 int32 + PLY 分段写）

- 版本：v0.6.63（链 0.6.62 → 0.6.63）。本地热更新包，未发布，未推中转站，未碰桌面。

- 改了什么：`app/echo_scene/voxels.py` + `app/installer/version.inc`（改号）。
  - 三角形直接用 int32 建：旧写法 int64 加完再转 int32；新写法模板先转 int32、序号直接用 int32 加。每个序号都小于 8n，8n−1 < 2³¹ 对装得进内存的云都成立，所以是数学上的等价；n 超过 268,435,455 时走旧的 int64 路，对一切 n 都一致。772 MB 的 int64 临时量（638 帧）与转换那一遍消失。
  - PLY 按行分段写：旧写法先建两个整文件临时量（vbuf 151 + fbuf 197 MB @120 帧）再写盘；新写法头不变、字节流不变，按行分段写。对任何长度都成立，不依赖行数是 8/12 的倍数（10 行顶点 + 13 行三角的怪输入直接对过，字节相同）。
  - 没动：顶点数学（float32 直接算会差 1 ulp，不碰）、GLB 分支（慢在 open3d 写文件器里，Python 这边改不了）、冻结的 docstring、`_tri_template`/`load_points_bin`/`stage_voxel_model`。行为未变——输出逐字节相同，冻结契约（一点一个方块、居中、用点自己的颜色）未动。
